# decisions/

> **M1.4 pattern + viața ta întreagă.** 1 fișier per decizie majoră documentată.

## De ce documentezi decizii

- **Future-self:** peste 6 luni nu mai ții minte de ce ai ales tool X. Citești fișierul, ai context.
- **Reflective practice:** scriind decizia, vezi mai clar trade-off-urile.
- **Demo pentru M5.5:** cele mai bune prezentări citează 2-3 decizii cheie din parcurs.

## Convenția de naming

`{YYYY-MM-DD}_{slug-decizie}.md`

Exemple:
- `2026-06-03_ce-stack-de-note-taking.md`
- `2026-06-10_cloud-vs-local-pentru-work-skills.md`
- `2026-07-15_alegerea-celor-3-automation-finale.md`

## Template

Vezi [_template-decision.md](_template-decision.md). Format scurt — 5-10 minute de scris.

## Workflow

1. **La final M1.4:** documentează prima decizie (ex: ce stack vrei să folosești)
2. **Pe parcursul cursului:** documentează 3-5 decizii cheie (ex: alegerea celor 3 din hartă, cloud vs local pentru work, choice de notification channel)
3. **La M5.5 demo:** citează 1-2 decizii ca să arăți „de ce" în spatele soluției
